# B2C Hakikisha

> **Status:** Implemented per the official docs in (Python, TypeScript). Live use requires approval and onboarding by Safaricom; sandbox apps are not provisioned for this API out of the box, so a sandbox call typically fails with `401.001 Invalid access token` or a `400` unless your app has been onboarded.

Validates a customer's identity details using a phone number before initiating a B2C (Business to Customer) payout. The API returns masked customer names to support verification while protecting customer privacy.

## Endpoint

`POST /mpesa/b2c/hakikisha/v1/hakikisha`

## Request

```json
{
  "header": {
    "requestID": "8aeefeea-8713-4a4d-b1b4-7b8c143b7ec1",
    "timestamp": "1748933384"
  },
  "body": {
    "msisdn": "254722000000",
    "shortcode": "123456"
  }
}
```

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `header.requestID` | string | auto | Unique request identifier. Auto-generated (UUID) by the SDK if omitted. |
| `header.timestamp` | string | auto | Request timestamp as a Unix epoch in seconds. Auto-generated by the SDK if omitted. |
| `body.msisdn` | string | yes | The phone number to look up, in `2547XXXXXXXX` format. |
| `body.shortcode` | string | yes | The organization's short code (5–7 digits). |

## Response

```json
{
  "header": {
    "requestID": "8aeefeea-8713-4a4d-b1b4-7b8c143b7ec1",
    "timestamp": "1748933384",
    "status": "200",
    "message": "Success"
  },
  "body": {
    "firstName": "john",
    "middleName": "M******",
    "lastName": "M******"
  }
}
```

| Field | Type | Description |
| --- | --- | --- |
| `header.requestID` | string | The request identifier echoed back. |
| `header.timestamp` | string | Timestamp indicating when the response was generated. |
| `header.status` | string | Response status code. `"200"` indicates success. |
| `header.message` | string | Human-readable status message. |
| `body.firstName` | string | Customer's first name. |
| `body.middleName` | string | Masked middle name to protect customer privacy. |
| `body.lastName` | string | Masked last name to protect customer privacy. |

On failure the API returns a `header` with a non-`"200"` `status` and a `body` containing a `message` (for example `"The customer does not exist."`).

## Usage

```python
from daraja import Mpesa

mpesa = Mpesa({"consumer_key": "...", "consumer_secret": "..."})
response = mpesa.b2c_hakikisha(
    {
        "header": {},  # requestID and timestamp are auto-generated
        "body": {"msisdn": "254722000000", "shortcode": "123456"},
    }
)
if response.header is not None:
    print(response.header.status, response.header.message)
if response.body is not None:
    print(response.body.firstName, response.body.middleName, response.body.lastName)
```

```typescript
import { Mpesa } from "daraja-sdk-ts";

const mpesa = new Mpesa({ consumerKey: "...", consumerSecret: "..." });
const response = await mpesa.b2cHakikisha.validate({
  header: {}, // requestID and timestamp are auto-generated
  body: { msisdn: "254722000000", shortcode: "123456" },
});
console.log(response.header.status, response.header.message);
console.log(response.body.firstName, response.body.middleName, response.body.lastName);
```

The service class is also available as `Mpesa.b2c_hakikisha_service` (Python) and as the `mpesa.b2cHakikisha` facade (TypeScript) — both expose the same `validate` method.

## Notes

- This is a synchronous POST request with no callback URLs.
- The `msisdn` must be a Safaricom number in `2547XXXXXXXX` format and the `shortcode` must be 5–7 digits; the SDKs reject other values with a `ValidationError` before sending.
- The API is **offered together with the C2B Hakikisha API under a reciprocal agreement** — see [C2B Hakikisha](c2b-hakikisha.md).
- **Onboarding required:** partners must be onboarded by Safaricom (contractual agreement) before the API works — see the [official B2C Hakikisha docs](https://developer.safaricom.co.ke/apis/B2CHakikisha) for the onboarding process.
