# STK Push Query

> **Status:**  Verified against the sandbox in all three SDKs (Go, Python, TypeScript).

Queries the result of a previously initiated STK push request.

## Endpoint

`POST /mpesa/stkpushquery/v1/query`

## Request fields

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `BusinessShortCode` | string | yes | Paybill or buy goods till number |
| `Password` | string | auto | Base64 of `BusinessShortCode + Passkey + Timestamp`. Auto-generated by the SDK when `passkey` is configured. |
| `Timestamp` | string | auto | `YYYYMMDDHHmmss`. Auto-generated by the SDK if omitted. |
| `CheckoutRequestID` | string | yes | The `CheckoutRequestID` returned from the STK push initiation |

## Response

| Field | Type | Description |
| --- | --- | --- |
| `ResponseCode` | string | `0` indicates the query was successful |
| `ResponseDescription` | string | Human-readable description |
| `MerchantRequestID` | string | The merchant request ID from the original STK push |
| `CheckoutRequestID` | string | The checkout request ID from the original STK push |
| `ResultCode` | string | `0` means the transaction was completed successfully |
| `ResultDesc` | string | Description of the transaction result |

## Usage

```python
from daraja import Mpesa, STKQueryRequest

mpesa = Mpesa({"consumer_key": "...", "consumer_secret": "...", "passkey": "..."})
response = mpesa.stk_query(STKQueryRequest(
    BusinessShortCode="174379",
    CheckoutRequestID="ws_CO_123456789",
))
```

```typescript
import { Mpesa } from "daraja-sdk-ts";

const mpesa = new Mpesa({ consumerKey: "...", consumerSecret: "...", passkey: "..." });
const response = await mpesa.stkPush.query({
  BusinessShortCode: "174379",
  CheckoutRequestID: "ws_CO_123456789",
  Password: "",
  Timestamp: "",
});
```

```go
package main

import (
    "context"
    "github.com/yourdudeken/daraja/sdks/go/client"
    "github.com/yourdudeken/daraja/sdks/go/types"
)

func main() {
    c := client.NewClient(types.MpesaConfig{
        ConsumerKey:    "...",
        ConsumerSecret: "...",
        Passkey:        "...",
        Environment:    types.Sandbox,
    })
    resp, err := c.STKQuery(context.Background(), types.STKQueryRequest{
        BusinessShortCode: "174379",
        CheckoutRequestID: "ws_CO_123456789",
    })
}
```

## Notes

- The SDK auto-generates `Password` and `Timestamp` from the configured `passkey` when they are not provided.
- `ResultCode` of `0` means the payment was completed. Any other value indicates the payment was not completed (e.g., `1032` = transaction cancelled by user, `1037` = timeout).
- Use this after [STK Push](./stk-push.md) to confirm whether the customer completed the payment.
