# STK Push (Lipa Na M-Pesa Online)

> **Status:**  Verified against the sandbox in all three SDKs (Go, Python, TypeScript).

Initiates a USSD prompt (STK push) on the customer's phone to authorize a payment.

## Endpoint

`POST /mpesa/stkpush/v1/processrequest`

## Request fields

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `BusinessShortCode` | int | yes | Paybill or buy goods till number |
| `Password` | string | auto | Base64 of `BusinessShortCode + Passkey + Timestamp`. Auto-generated by the SDK when `passkey` is configured. |
| `Timestamp` | string | auto | `YYYYMMDDHHmmss`. Auto-generated by the SDK if omitted. |
| `TransactionType` | string | yes | `CustomerPayBillOnline` or `CustomerBuyGoodsOnline` |
| `Amount` | int | yes | Transaction amount (1–250,000) |
| `PartyA` | int | yes | Customer phone number sending the money |
| `PartyB` | int | yes | Business shortcode receiving the money |
| `PhoneNumber` | int | yes | Customer phone number to receive the STK prompt |
| `CallBackURL` | string | yes | HTTPS URL to receive the transaction result callback |
| `AccountReference` | string | yes | Max 12 characters. Account reference shown to the customer. |
| `TransactionDesc` | string | yes | Max 13 characters. Description of the transaction. |

## Response

| Field | Type | Description |
| --- | --- | --- |
| `MerchantRequestID` | string | Unique ID for the merchant request |
| `CheckoutRequestID` | string | Unique ID for the checkout request (used to query status) |
| `ResponseCode` | string | `0` indicates success |
| `ResponseDescription` | string | Human-readable description of the result |
| `CustomerMessage` | string | Message displayed to the customer |

## Usage

```python
from daraja import Mpesa, STKPushRequest

mpesa = Mpesa({"consumer_key": "...", "consumer_secret": "...", "passkey": "..."})
response = mpesa.stk_push(STKPushRequest(
    BusinessShortCode=174379,
    TransactionType="CustomerPayBillOnline",
    Amount=1000,
    PartyA=254712345678,
    PartyB=174379,
    PhoneNumber=254712345678,
    CallBackURL="https://example.com/callback",
    AccountReference="Order123",
    TransactionDesc="Payment",
))
```

```typescript
import { Mpesa } from "@daraja-sdk/ts";

const mpesa = new Mpesa({ consumerKey: "...", consumerSecret: "...", passkey: "..." });
const response = await mpesa.stkPush.initiate({
  BusinessShortCode: 174379,
  TransactionType: "CustomerPayBillOnline",
  Amount: 1000,
  PartyA: 254712345678,
  PartyB: 174379,
  PhoneNumber: 254712345678,
  CallBackURL: "https://example.com/callback",
  AccountReference: "Order123",
  TransactionDesc: "Payment",
  Password: "",
  Timestamp: "",
});
```

```go
package main

import (
    "context"
    "github.com/yourdudeken/daraja/sdks/go/client"
    "github.com/yourdudeken/daraja/sdks/go/types"
)

func main() {
    c := client.NewClient(types.MpesaConfig{
        ConsumerKey:    "...",
        ConsumerSecret: "...",
        Passkey:        "...",
        Environment:    types.Sandbox,
    })
    resp, err := c.STKPush(context.Background(), types.STKPushRequest{
        BusinessShortCode: 174379,
        TransactionType:   types.CustomerPayBillOnline,
        Amount:            1000,
        PartyA:            254712345678,
        PartyB:            174379,
        PhoneNumber:       254712345678,
        CallBackURL:       "https://example.com/callback",
        AccountReference:  "Order123",
        TransactionDesc:   "Payment",
    })
}
```

## Notes

- The SDK auto-generates `Password` and `Timestamp` from the configured `passkey` when they are not provided.
- `AccountReference` is truncated to 12 characters; `TransactionDesc` is truncated to 13 characters.
- Amount is validated to be between 1 and 250,000.
- The response only indicates that the request was accepted. The actual transaction result arrives via the callback URL.
- Use `CheckoutRequestID` from the response with [STK Query](./stk-query.md) to check the payment status.
