# Introduction

Daraja is the Safaricom M-Pesa developer API. This monorepo provides SDKs in
three languages (Python, TypeScript, and Go) plus a Model Context Protocol (MCP)
server that exposes these docs to AI coding assistants.

## What's included

- `packages/python` — Python SDK (package `daraja`)
- `packages/typescript` — TypeScript SDK (package `@daraja-sdk/ts`)
- `packages/go` — Go SDK (module `.../go`)
- `mcp` — MCP server for searching these docs
